今天的 GitHub 热榜被 AI 工具包圆了，但最出圈的，是一个两天前才发布的小工具。以下数据为 2026-11-18 快照，星数与涨幅来自各仓库页面当日读数。

## 1. Wireless-Device-Battery-Monitor：两天前发布，杀进热榜

★3,384 · C++ · 2026 年 11 月 16 日发布

把无线鼠标、耳机、键盘、手柄的电量，直接显示到 Windows 10/11 的任务栏上，再也不用为了看电量去装罗技、雷蛇各家的全家桶软件。支持罗技、雷蛇、SteelSeries、海盗船、HyperX、DualSense、Xbox 手柄以及普通蓝牙设备。一个小而美的工具，两天冲进热榜，说明大家真的被厂商软件折磨很久了。

仓库：https://github.com/krisgfx9/Wireless-Device-Battery-Monitor

## 2. T3 Code：用手机遥控编程 Agent

★64,642 · TypeScript · 今日约 +2,064 星

用手机或任何一台电脑，远程操控 Claude Code、Codex 等编程 Agent 干活：出门在外也能看进度、给指令。Agent 写代码、人在远方指挥，正在成为新的工作方式。

仓库：https://github.com/pingdotgg/t3code

## 3. 阿里 Open Code Review：会做代码审查的 Agent

★54,060 · Go

阿里开源的代码审查工具，采用「确定性流水线 + LLM Agent」的混合架构：规则引擎保证底线，Agent 负责理解上下文，给出精确到行的审查评论。内置空指针（NPE）、线程安全、XSS、SQL 注入等检查规则，对团队落地 code review 很有参考价值。

仓库：https://github.com/alibaba/open-code-review

## 4. agent-browser：给 AI Agent 用的浏览器

★52,503 · Rust · 本周约 +3,429 星

Vercel 出品的浏览器自动化 CLI，专门为 AI Agent 设计：让 Agent 能打开网页、点击、填表、抓取内容。Agent 要真正「上网干活」，浏览器就是它的手和眼，这个位置正在被快速占领。

仓库：https://github.com/vercel-labs/agent-browser

## 5. Univer：开源版 Office SDK

★29,748 · TypeScript · 今日约 +1,774 星

开源的 Office 套件 SDK，可以把文档、表格、幻灯片和在线协作能力，直接嵌进你自己的产品里。自研在线文档的团队，不用再从零造轮子。

仓库：https://github.com/dream-num/univer

## 趋势解读

五个工具里，四个和 AI Agent 直接相关：遥控 Agent 的、给 Agent 做审查的、给 Agent 当浏览器的、给 Agent 时代准备的办公基础设施。唯一的「非 AI」工具，反而靠解决一个真实的小痛点两天杀进榜单。

结论很清晰：Agent 基础设施正在爆发，而好工具的另一个标准从未变过——解决一个具体的问题。
