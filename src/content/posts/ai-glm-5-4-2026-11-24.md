智谱 11 月 23 日发布 GLM-5.4，这是它第一个基于 Loop Transformer 架构的旗舰模型。以下信息来自智谱官方博客，数据为 2026-11-24 快照。

## 换了个思路：不加层，让层多跑一遍

大模型过去几年一直在比谁更大，GLM-5.4 换了个方向。它的底座约 7500 亿参数，只有 28 层，Loop Transformer 的做法是让这 28 层在一次前向计算里跑两遍，第二遍复用同一套权重，把第一遍的结果再加工一轮。网络的“思考深度”翻了一倍，参数量没变。

智谱说，这套设计在 10 亿、40 亿、300 亿和 7500 亿四个规模的底座上都验证过。GLM-5.4 不是从头训练的，是拿已有的 GLM-5 底座继续训练，让它学会“跑两遍”。

为了让第二遍不贵，官方博客提了三处工程处理：每层输出经过逐 token 的门控再写回，第一遍写得谨慎、第二遍再修正；第二遍复用第一遍的 KV 缓存，只保留自己的小滑动窗口；第二遍复用第一遍的稀疏注意力选择，不再重新算一遍索引。

## 发布了什么

- **视觉能力**：旗舰线第一次能直接读截图和图片，写代码时可以对着界面图来。
- **100 万 token 上下文**：在 Claude Code 里选 glm-5.4[1m]，其他工具里是 glm-5.4。
- **速度**：官方说法是空闲时最高每秒 200 个 token，高峰时 70 到 80 个。这是官方说法，第三方还没法验证。
- **智能水平**：官方说法是可比 2 万亿到 3 万亿参数的模型。同样是官方说法——这次发布没有附任何 benchmark 分数，智谱说分数晚些再公布。

目前 GLM-5.4 只对 GLM Coding Plan 的订阅用户开放，也在 ZCode 和 Z.ai Chat 里。按量计费的 API 要等安全评估之后才开，模型权重计划在安全加固完成后开源，都没有给出时间。

## 怎么看这次发布

有意思的点在路线选择上。上周三家实验室一周连发模型，方向都是让 Agent 长时间干活、把成本压下来；GLM-5.4 用“循环”代替“堆规模”，如果这条路走得通，追前沿的成本会低很多。但现在下结论还太早：没有公开 benchmark，智能水平的说法只能先记在账上，等分数出来再看。智谱管理层还透露，约 3 万亿参数的 GLM-5.5 预计 12 月发布，到时候可以对照着看。
